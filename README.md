# フィジカルAI レポート & ノートアプリ

## 中身

- `report/physical-ai-report.md` — フィジカルAIの調査レポート（2026年10月時点）
- `app/index.html` — レポートをノートとして整理・追記できるノートアプリ

## ノートアプリの使い方

`app/index.html` をブラウザで開くだけで動きます（インストール不要）。

- 初回起動時に、レポートが見出し（`##`）ごとのノートとして自動で取り込まれます
- ノートの作成・編集・削除（本文は Markdown）
- キーワード検索、タグでの絞り込み
- 任意の Markdown ファイルを取り込み（見出しごとに分割）
- Markdown / JSON で書き出し、JSON の読み込み
- ライト／ダークテーマ切り替え

ノートはブラウザの localStorage に保存されます。別の端末やブラウザに移すときは JSON で書き出してください。

レポートを更新したら、アプリに埋め込むデータを再生成します:

```sh
node app/build-seed.js
```
